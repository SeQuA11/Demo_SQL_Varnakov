ЗАПРОС 1. НОМЕРНОЙ ФОНД
==============================================================================
Вывести список всех номеров гостиницы: этаж, номер и категория номера, упорядоченный по этажам и номерам.

Скрипт запроса:

SELECT f.number || ' этаж' AS "Этаж",
       r.number            AS "Номер",
       c.name              AS "Категория"
FROM room r
JOIN floor f         ON f.id = r.floor_id
JOIN room_category c ON c.id = r.category_id
ORDER BY f.number, r.number;

Соответствие БД и результат отладки:
  - Таблицы: room, floor, room_category.
  - Соответствует полностью: 25 строк, совпадают с документом заказчика построчно.

==============================================================================
ЗАПРОС 2. ОТЧЕТ ПО СОСТОЯНИЮ НОМЕРНОГО ФОНДА НА ДАТУ
==============================================================================
На заданную дату вывести по каждому номеру: этаж, номер, категорию, статус (Занят, Чистый, Грязный, Назначен к уборке) и дату выезда постояльца, если номер занят. Номера сгруппированы по этажам.

Скрипт запроса:

WITH params AS (SELECT DATE '2025-03-01' AS d)
SELECT f.number || ' этаж' AS "Этаж",
       r.number            AS "Номер",
       c.name              AS "Категория",
       s.name              AS "Статус",
       to_char((SELECT min(st.check_out)
                FROM stay st
                WHERE st.room_id = r.id
                  AND st.check_in <= p.d
                  AND (st.check_out IS NULL OR st.check_out >= p.d)),
               'DD.MM.YYYY') AS "Дата выезда"
FROM params p
CROSS JOIN room r
JOIN floor f         ON f.id = r.floor_id
JOIN room_category c ON c.id = r.category_id
LEFT JOIN LATERAL (SELECT l.status_id
                   FROM room_status_log l
                   WHERE l.room_id = r.id AND l.status_date <= p.d
                   ORDER BY l.status_date DESC
                   LIMIT 1) ls ON true
LEFT JOIN room_status s ON s.id = ls.status_id
ORDER BY f.number, r.number;

Соответствие БД и результат отладки:
  - Таблицы: room, floor, room_category, room_status, room_status_log, stay.
  - Статус хранится в журнале room_status_log с датой — это и есть «состояние на дату».
  - Дата выезда не хранится в номере (3НФ), а берётся из таблицы заселений stay: ближайший выезд среди постояльцев, живущих в номере на эту дату.
  - Результат: 25 строк, все статусы совпадают с документом заказчика. Даты выезда совпадают, кроме трёх номеров с ошибками в исходных данных:
    104 — выезд 02.02.2025 раньше въезда 23.02.2025, в БД дата не указана;
    110 — выезд записан как «02.02.205» (опечатка), в БД дата не указана;
    206 — у заказчика 02.02.2025, но это раньше даты отчёта, поэтому на 01.03.2025 постояльца в номере нет (см. проверку 4).
  - Номер 107: живут двое, выводится ближайший выезд 17.03.2025 — как у заказчика.

==============================================================================
ЗАПРОС 3. ПОСТОЯЛЬЦЫ, ЖИВУЩИЕ СЕЙЧАС В ГОСТИНИЦЕ
==============================================================================
Вывести постояльцев, которые проживают в гостинице на текущую дату: этаж, номер, категорию, ФИО клиента, дату въезда и дату выезда.

Скрипт запроса:

WITH params AS (SELECT DATE '2025-03-01' AS d)
SELECT f.number || ' этаж' AS "Этаж",
       r.number            AS "Номер",
       c.name              AS "Категория",
       concat_ws(' ', g.last_name, g.first_name, g.patronymic) AS "Клиент",
       to_char(st.check_in,  'DD.MM.YYYY') AS "Въезд",
       to_char(st.check_out, 'DD.MM.YYYY') AS "Выезд"
FROM params p
JOIN stay st ON st.check_in <= p.d
            AND (st.check_out IS NULL OR st.check_out >= p.d)
JOIN guest g         ON g.id = st.guest_id
JOIN room r          ON r.id = st.room_id
JOIN floor f         ON f.id = r.floor_id
JOIN room_category c ON c.id = r.category_id
ORDER BY f.number, r.number, g.last_name;

Соответствие БД и результат отладки:
  - Таблицы: stay, guest, room, floor, room_category.
  - «Сейчас» — это дата из params: в отчёте 01.03.2025 (дата документов заказчика), в работающей ИС подставляется CURRENT_DATE.
  - Постоялец живёт на дату, если въезд не позже этой даты, а выезд не раньше (или дата выезда не известна).
  - Результат: 17 постояльцев. В документе заказчика 18: Гладилина В. М. (номер 206) по данным въехала и выехала 02.02.2025, поэтому на 01.03.2025 она не проживает. Остальные 17 записей совпадают.

ЗАПРОС 4. Проверка: статус номера не совпадает с заселениями на дату
------------------------------------------------------------------------------
Найти номера со статусом «Занят», в которых на дату нет постояльца, и номера с постояльцем, у которых статус не «Занят».

Скрипт запроса:

WITH params AS (SELECT DATE '2025-03-01' AS d),
state AS (
    SELECT r.id, r.number, s.name AS status,
           EXISTS (SELECT 1 FROM stay st
                   WHERE st.room_id = r.id
                     AND st.check_in <= p.d
                     AND (st.check_out IS NULL OR st.check_out >= p.d)) AS has_guest
    FROM params p
    CROSS JOIN room r
    LEFT JOIN LATERAL (SELECT l.status_id
                       FROM room_status_log l
                       WHERE l.room_id = r.id AND l.status_date <= p.d
                       ORDER BY l.status_date DESC
                       LIMIT 1) ls ON true
    LEFT JOIN room_status s ON s.id = ls.status_id
)
SELECT number AS "Номер", status AS "Статус",
       CASE WHEN has_guest THEN 'есть' ELSE 'нет' END AS "Постоялец на дату"
FROM state
WHERE (status = 'Занят') <> has_guest
ORDER BY number;

Результат: 1 номер — 206 («Занят», постояльца нет). Это ошибка в данных заказчика, её нужно уточнить.

------------------------------------------------------------------------------
ЗАПРОС 5. Проверка: заселения без известной даты выезда
------------------------------------------------------------------------------
Вывести постояльцев, у которых не указана дата выезда.

Скрипт запроса:

SELECT r.number AS "Номер",
       concat_ws(' ', g.last_name, g.first_name, g.patronymic) AS "Клиент",
       to_char(st.check_in, 'DD.MM.YYYY') AS "Въезд"
FROM stay st
JOIN guest g ON g.id = st.guest_id
JOIN room r  ON r.id = st.room_id
WHERE st.check_out IS NULL
ORDER BY r.number;

Результат: 5 записей — номера 102, 104, 110, 209, 306. Для 104 и 110 дата выезда была ошибочной и не загружена, для остальных её нет у заказчика.
